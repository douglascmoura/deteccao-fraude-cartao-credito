# 📁 Dataset: Credit Card Fraud Detection

Devido às restrições de tamanho de arquivo do GitHub (limite de 100 MB por arquivo), o arquivo bruto `creditcard.csv` (~150 MB) está listado no `.gitignore` e não é versionado no repositório.

### 📥 Instruções para Download:
1. Acesse o dataset oficial no Kaggle:  
   👉 [Credit Card Fraud Detection on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
2. Faça o download do arquivo compactado `creditcard.csv.zip`.
3. Descompacte o arquivo `creditcard.csv` diretamente dentro desta pasta `data/`.
